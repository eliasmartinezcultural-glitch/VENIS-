# VENIS V1.7 — LOCK

## Estado
BASE VISUAL PROFUNDA · PRODUCCIÓN

## Objetivo
Convertir la biblioteca de VENIS en un sistema de productos visuales, no en un conjunto de configuraciones.

## Arquitectura visual
EVENTO → FAMILIA VISUAL → PRODUCTO CURADO → COMPOSICIÓN → PALETA → TIPOGRAFÍA → DECORACIÓN → ASSET → FOTO → MOTOR → INVITACIÓN

## Biblioteca interna
El motor contiene familias Festivo, Romántico, Quince, Boda, Infantil, Bautismo, Elegante, Musical, Graduación, Aniversario, Moderno y Corporativo, con productos art-directed específicos por evento.

## Regla de interfaz
El cliente sigue viendo una selección pequeña y simple. La complejidad vive en el sistema interno.

## Regla de diseño
Cada producto debe cambiar composición, jerarquía, asset, densidad y personalidad; no alcanza con cambiar colores.

## Regla técnica
No modificar flujo, persistencia, publicación por hash, WhatsApp, Maps ni compatibilidad de enlaces anteriores para sumar diseño.

## Assets
Vector-first, SVG inline, sin dependencias externas. Cada portada admite un motivo visual controlado y fotografía opcional.

## Calidad
Mobile legibility · date/time scan · venue scan · contrast · overflow · visual coherence.
