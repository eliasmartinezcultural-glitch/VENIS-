# VENIS V1.6 — VISUAL ASSET ENGINE LOCK

Estado: BLOQUEADO COMO CAPA VISUAL

V1.6 agrega profundidad al producto sin alterar el flujo de producción.

## Arquitectura

EVENTO → RECOMENDACIÓN → BIBLIOTECA → RECETA → DIRECCIÓN DE ARTE → ASSET ENGINE → MOTOR → INVITACIÓN FINAL

## Activos

- stickers vectoriales livianos
- mini ilustraciones temáticas
- ornamentos
- patrones
- tratamiento fotográfico
- fallback visual cuando no hay foto
- asset temático por tipo de evento
- asset temático por familia de plantilla

## Ley central

Los recursos visuales no se agregan para llenar espacio.

Cada dibujo, sticker, patrón o tratamiento debe cumplir al menos una función:

1. reforzar la identidad del evento;
2. crear una composición reconocible;
3. mejorar la sensación de producto terminado;
4. conservar legibilidad móvil.

## Fotos

La foto del cliente continúa siendo opcional. Si existe, domina la portada y el sistema aplica el tratamiento visual de la plantilla. Si no existe, VENIS usa un recurso vectorial propio.

No se incorporan dependencias externas obligatorias.

## Compatibilidad

No se modifica:

- modelo de datos;
- enlaces existentes;
- guardado local;
- WhatsApp;
- Maps;
- flujo Evento → Estilo → Datos → Publicar;
- motor de resolución de estilos.

## Regla de producto

Seis plantillas deben seguir pareciendo seis productos diferentes. Los assets son una capa de dirección de arte, no seis colores de la misma página.
