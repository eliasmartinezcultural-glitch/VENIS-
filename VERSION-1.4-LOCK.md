# VENIS · VERSION 1.4 LOCK

## Biblioteca visual de producto

V1.4 transforma la selección de estilo en una **biblioteca de productos visuales**.

El usuario no necesita comprender:
- paletas;
- tipografías;
- componentes;
- layout;
- decoración.

Ve una dirección visual y la elige.

## Arquitectura

**EVENTO → RECOMENDACIÓN → BIBLIOTECA → RECETA → MOTOR → INVITACIÓN**

Cada receta sigue siendo datos, no una página independiente.

## Biblioteca actual

1. Elegante — editorial / noche / serif / ornamentos.
2. Romántico — centrado / rosa / clásico / botánico.
3. Fiesta — poster / fiesta / tipografía fuerte / estrellas.
4. Sereno — aireado / botánica / suave / botánico.
5. Moderno — split / azul / sans / geometría.
6. Minimal — limpio / blanco / sans / líneas.

Cada tarjeta incluye una representación visual resumida de su composición, no solamente una muestra de color.

## Regla de producto

La biblioteca debe responder en menos de unos segundos a:

**“¿Cuál quiero vender?”**

No debe obligar al cliente a estudiar el sistema.

## Regla de fabricación

Agregar una nueva plantilla significa agregar una nueva receta/composición al sistema.

No se permite copiar una página completa para fabricar otra invitación.

## Próxima capa

La siguiente evolución será:
- biblioteca de activos de portada;
- sistema de imágenes;
- variaciones controladas por plantilla;
- presets comerciales;
- control de calidad antes de entregar;
- flujo de entrega al cliente.

No se debe convertir la pantalla principal en un panel técnico.
