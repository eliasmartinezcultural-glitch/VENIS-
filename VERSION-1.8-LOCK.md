# VENIS V1.8 — LOCK

## Dirección artística profunda
VENIS ya no trata las recetas como combinaciones técnicas. Cada producto posee una dirección artística propia.

## Capas
EVENTO → FAMILIA → PRODUCTO → HERO → COMPOSICIÓN → MOTIVO → ESCALA → OPACIDAD → SUPERFICIE → RITMO → FECHA → MENSAJE → FOTO → MOTOR

## Productos art-directed
Cada receta principal define una identidad visual independiente: lujo nocturno, ceremonial, poster burst, luz botánica, arquitectura, galería silenciosa, cascada de globos, estudio de torta, fuegos artificiales, corona editorial, estelar, floral, anillos, jardín, votos modernos, luz matinal, bautismo botánico, clásico luminoso, arquitectura corporativa, editorial nocturno y poster creativo.

## Regla comercial
Una opción visible debe parecer un producto terminado, no una configuración.

## Regla de diseño
La diferencia entre productos debe surgir de composición, ritmo, jerarquía, tratamiento del motivo, superficie y tipografía; no solamente de color.

## Regla UX
La complejidad permanece en el sistema. El usuario sigue trabajando con una selección corta y directa.

## Regla técnica
No alterar publicación, hash-links, guardado local, WhatsApp, Maps ni compatibilidad mientras se profundiza el diseño.
