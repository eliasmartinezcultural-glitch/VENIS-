# VENIS · VERSION 1.9

## Estado
**PROFUNDIDAD DE PRODUCTO / COLECCIONES VISUALES**

V1.9 no cambia el flujo comercial ni el motor de publicación. Profundiza la capa visual interna para que cada familia funcione como una pequeña colección de productos profesionales.

## Nueva arquitectura visual

EVENTO → FAMILIA → PRODUCTO → VARIANTE → COMPOSICIÓN → PATRÓN → MARCO → ORNAMENTO → TRATAMIENTO FOTOGRÁFICO → FECHA → MENSAJE → MOTOR

## Familias profundas

Festivo · Romántico · Quince · Boda · Infantil · Bautismo · Elegante · Musical · Graduación · Aniversario · Moderno · Corporativo.

Cada familia dispone de tres direcciones internas y sistemas propios de composición, patrón, marco, ornamento, fotografía y fecha.

## Regla de producto

Una variante no es un cambio cosmético. Cambia la forma de leer la invitación, el tratamiento de la portada, la arquitectura de la información y el lenguaje decorativo.

## Regla UX

El cliente sigue viendo una selección corta y fácil. La profundidad queda dentro del motor.

## Conservado

- publicación mediante enlace/hash
- guardado local
- compartir
- WhatsApp
- Maps
- compatibilidad de invitaciones existentes
- flujo Evento → Estilo → Datos → Publicar

## Regla de calidad

No agregar elementos por cantidad. Cada capa debe reforzar identidad, jerarquía, legibilidad móvil y sensación de producto terminado.
