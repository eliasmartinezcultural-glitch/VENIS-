# VENIS · VERSION 1.5 LOCK

## Dirección de arte y acabado de producto

V1.5 profundiza exclusivamente la capa visual sobre la arquitectura existente.

### LEY CENTRAL

**No se modifica el flujo, el modelo de datos, la publicación, el guardado, el enlace, WhatsApp, Maps ni la lógica de fabricación.**

La intervención queda limitada a:
- composición;
- jerarquía visual;
- tipografía;
- ritmo y espacio;
- tratamiento de tarjetas de biblioteca;
- acabados de portada;
- personalidad de las seis familias;
- decoración controlada;
- responsive visual;
- percepción de producto terminado.

### Dirección de arte

Cada invitación debe tener un foco visual principal y una jerarquía inequívoca:
**nombre → fecha/hora → lugar → mensaje → acciones.**

Las seis familias dejan de comportarse como simples combinaciones de variables y pasan a tener una dirección compositiva propia:

1. **Elegante / Editorial** — editorial, contrastada, tipográfica.
2. **Romántico / Romance** — centrado, delicado, ceremonial.
3. **Fiesta / Celebration** — alto impacto, energético, protagonista.
4. **Sereno / Soft** — aireado, orgánico, familiar.
5. **Moderno / Modern** — arquitectónico, dividido, contemporáneo.
6. **Minimal / Minimal** — silencioso, preciso, premium.

### Regla de calidad

No se agrega decoración para llenar espacio.
No se agrega color porque sí.
No se agregan componentes para aparentar profundidad.

Cada decisión visual debe mejorar al menos una de estas variables:
- claridad;
- personalidad;
- jerarquía;
- legibilidad móvil;
- sensación de producto terminado.

### Próxima capa

La siguiente profundidad visual será el **sistema de activos de portada**, sin convertirlo en una nueva pantalla técnica: tratamientos de imagen, recortes, encuadres, fondos y recursos gráficos controlados por receta.
